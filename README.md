
# 🌐 Villaema Web

Este repositorio contiene el código fuente de **Villaema Web**, un proyecto orientado a mostrar mi portfolio profesional, proyectos destacados y ofrecer información sobre mis servicios como desarrolladora Full Stack.

---

## 📖 Descripción

**Villaema Web** es una aplicación web diseñada para:
- Presentar mi **portfolio personal**.
- Mostrar proyectos desarrollados en diferentes tecnologías.
- Ofrecer un espacio para contacto profesional.

El objetivo es crear una plataforma moderna, responsive y optimizada para ofrecer una experiencia fluida tanto en escritorio como en dispositivos móviles.

---

## 🚀 Tecnologías utilizadas

- **Frontend**:  
  HTML5 | CSS3 | JavaScript | Bootstrap  

- **Backend**:  
  PHP | MySQL  

- **Herramientas**:  
  Git | GitHub | XAMPP

## ⚙️ Instalación y uso

1. **Clona el repositorio**:

```plaintext
   git clone https://github.com/tatvil/villaemaweb.git
```

Configura el entorno local:

Instala https://www.apachefriends.org/es/index.html o cualquier servidor con soporte PHP y MySQL.
Copia los archivos en la carpeta htdocs (o equivalente).

Accede desde el navegador:
```plaintext
 http://localhost/villaemaweb/
```
